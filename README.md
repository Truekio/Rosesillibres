# Tareas

App Android personal de tareas diarias: avisos múltiples, tareas recurrentes, posponer con un toque, categorías de colores y widget.

El APK se compila automáticamente con GitHub Actions y se publica en **Releases** (`Tareas.apk`).

## Instalar
1. En el móvil, abre la última release y descarga `Tareas.apk`.
2. Permite "instalar apps desconocidas" para el navegador cuando te lo pida.
3. Abre la app y acepta las notificaciones.
4. Mantén pulsado el escritorio → Widgets → Tareas.
